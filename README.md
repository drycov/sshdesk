# SSHDesk

Local-first SSH/SFTP desktop client and Chromium browser extension (experimental).

Features in the browser prototype include SSH Agent, OS keychain integration, jump hosts, local/remote/SOCKS5 tunneling, split terminal panes, snippets, OpenSSH config import and encrypted manual device sync.

**Security:** the Chromium extension requires a locally installed Native Messaging Host. Browser extensions cannot open raw SSH TCP sockets directly. This project is an experimental MVP and has not passed production security or live integration testing.

Source release: SSHDesk Browser v0.2.1 (full source bundle distributed separately while GitHub publication is completed).
